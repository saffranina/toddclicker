# Todd Howard S.A. 💰

Un idle clicker satírico donde le sacás pesos a Todd Howard a puro click para comprarle Skyrim de vuelta. Otra vez.

🎮 **Jugalo acá:** https://saffranina.github.io/toddclicker/

## Qué tiene

- **Clickeá a Todd** para ganar pesos — la foto rota al azar entre distintos memes clásicos, y cada click dispara una de varias frases icónicas ("It just works", "Imma make videogames", etc.).
- **Tienda de re-releases y DLC**: desde un "Parche day-one" hasta el "Yate de Todd", cada compra sube tu plata por click o por segundo.
- **Efectos de desbloqueo**: flip con espejo horizontal, rebote, chispas doradas y un woosh sintetizado en cada compra.
- **Aviso de disponibilidad**: cuando juntás la plata para algo, el ítem brilla y suena una campanita antes de que lo compres.
- **Pop-up satírico de "Pase de Batalla"** al comprar Skyrim VR — aceptás (es gratis) y tus monedas se multiplican x100.
- **Recompensa especial** al comprar el Yate de Todd.
- **Un pescador** debajo de las estadísticas, para entretenerte mientras esperás *The Elder Scrolls VI*.
- Todo el audio (caja registradora, woosh, ding, splash) está sintetizado con la Web Audio API — cero archivos de sonido externos.

## Cómo correrlo local

Es un único archivo HTML autocontenido (imágenes y audio embebidos en base64). Solo abrí `index.html` en el navegador.
